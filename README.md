# Sales Performance Analysis – Power BI

## Project Overview
This project analyzes sales data using Power BI to identify revenue trends, top salespersons, regional performance, product sales, and discount patterns.

## Tools Used
- Microsoft Power BI
- Data Visualization

## Key Tasks
- Calculate total revenue.
- Identify top 5 salespersons.
- Analyze monthly revenue trends.
- Find the best-performing region.
- Analyze discounts and product sales.
- Compare revenue by region and category.
- Identify the highest-revenue order.
- Calculate average unit price by category.

## Project Files
- `Sales_Performance_Analysis.pbix` – Power BI report.
- `Sales_Performance_Insights.docx` – Insights report.

Data Analysis, Power BI, Data Visualization, Business Intelligence.
